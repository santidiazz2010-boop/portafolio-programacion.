# Portafolio de Santiago Díaz Zapata

Sitio web estático creado con HTML, CSS y JavaScript.

## Archivos
- `index.html`: contenido y secciones del portafolio.
- `styles.css`: diseño adaptable a computador y celular.
- `script.js`: menú móvil y año automático.
- `img/`: carpeta reservada para capturas o imágenes de proyectos.

## Cómo verlo
Abre `index.html` en un navegador.

## Cómo publicarlo en GitHub Pages
1. Inicia sesión en https://github.com/
2. Crea un repositorio llamado `portafolio-programacion-santiago`.
3. Sube `index.html`, `styles.css`, `script.js`, `README.md` y la carpeta `img`.
4. En el repositorio, abre **Settings → Pages**.
5. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio. La dirección tendrá el formato `https://TU-USUARIO.github.io/portafolio-programacion-santiago/`.

## Enlaces de proyectos
Los botones de GitHub de las tarjetas están provisionales. Cuando publiques cada proyecto, cambia `https://github.com/` en `index.html` por el enlace real del repositorio correspondiente.

## Antes de publicar
- Revisa qué datos de contacto quieres hacer públicos.
- No subas contraseñas, claves, bases de datos con información real ni documentos privados.
- Confirma que puedes compartir el código de cada proyecto grupal.
